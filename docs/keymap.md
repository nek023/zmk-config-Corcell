# キーマップ

[README](../README.md) に戻る

CLine46 の数字・矢印、記号、機能レイヤーを、zen と同じ 50 キー配置に合わせています。
ソースは [config/corcell.keymap](../config/corcell.keymap)、図は
[keymap-drawer/corcell.svg](../keymap-drawer/corcell.svg) です。
記号は参考元と同じ US 配列用のキーコードです。

## 基本配列

- QWERTY。右ホーム段の末尾は `;` と Enter、下段の末尾は `/` と `'`。
- Tab は短押しで Tab、長押しで左 Ctrl。
- `;`・`:` の位置は短押しで `;` (Shift 併用で `:`)、200 ms の長押しでトラックボールの縦スクロール。
- 左の最下段は、外側から未割り当て、Alt+Space、左 Alt、左 GUI、Space/NUM、Space。
- 右の最下段は、内側から Space、Space/SYM、トラックボール、右 Command、右 Alt、Alt+Space。
  トラックボールの位置に対応するキーの割り当ては無効です。
- B と N の内側の追加キーはどちらも Space。
- Alt+Space は押すたびに 1 回だけ送信します。

## レイヤー

| 番号 | 名前 | 有効にする操作 | 主な割り当て |
| --- | --- | --- | --- |
| 0 | DEFAULT | 通常時 | 基本配列 |
| 1 | NUM | 左 Space/NUM を長押し | 上段に 1〜0、H/J/K/L に左/下/上/右 |
| 2 | SYM | 右 Space/SYM を長押し | 上段に !〜)、右側に記号・括弧 |
| 3 | FN | 右下段末尾の `'` を長押し | Bluetooth、音量、矢印、ブートローダー |
| 4 | SCROLL | `;` を長押し | 左右のトラックボールを縦スクロールに切り替え |

Space/NUM、Space/SYM、`'`/FN は短押しすると通常の文字を入力します。
NUM・SYM・FN の未割り当て位置は、参考元と同じく通常文字の入力を抑止します。
修飾キーと親指キーは透過するため、押したレイヤーキーを離すと元に戻ります。

## マウスとエンコーダー

- DEFAULT と SCROLL で J+K は左クリック、K+L は右クリック、J+K+L は中クリック。
  コンボを押したままにすると、クリックを保持してドラッグできます。
  文字入力との誤判定を抑えるため、直前 100 ms にキー入力がない場合に有効になります。
- オートマウスは無効です。トラックボールを動かしても J/K/L の文字入力は切り替わりません。
- `;` を 200 ms 長押しすると SCROLL (レイヤー 4) が有効になり、左右のトラックボールが縦スクロールになります。
  先にトラックボールを動かす必要はありません。離すとカーソル移動に戻り、`;` は送信しません。
  判定時間より短く押して離すと通常の `;` を入力します (Shift 併用で `:`)。判定前のトラックボール操作はカーソル移動です。
  スクロール倍率は `1/24`、カーソル移動倍率は `3/4` です。
- FN (レイヤー 3) ではトラックボールは通常のカーソル移動です。
- エンコーダーは全レイヤーで音量の増減です。

## Bluetooth・機能キー

FN を押したまま操作します。位置は DEFAULT の文字を基準にしています。

| 位置 | 操作 |
| --- | --- |
| Q/W/E/R/T | Bluetooth 接続先 0/1/2/3/4 |
| Esc | 選択中の Bluetooth 接続先の登録を消去 |
| A/S/D | 音量を下げる/上げる/ミュート |
| Y または B | ブートローダーへ移行 |
| O | Scroll Lock |
| P | Pause/Break |
| L | 上矢印 |
| `,` / `.` / `/` | 左/下/右矢印 |

通常版では Studio を有効にしていないため、zen の Studio Unlock の位置は未割り当てです。
README の upstream 向け接続ガイドに書かれた初期配列のキー位置とは異なります。
Bluetooth 接続先 0 は FN+Q で選んでください。
